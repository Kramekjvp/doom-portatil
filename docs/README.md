# docs

- `adr/` — decisões de arquitetura, uma por arquivo, numeradas
  (`0001-...md`, `0002-...md`, ...). Cada uma registra contexto,
  alternativas consideradas, decisão e consequências.
- `requirements.md` — requisitos formais do MVP, derivados do roteiro de
  produção do projeto (a formalizar).

Este material é reaproveitado diretamente no relatório final da disciplina.
